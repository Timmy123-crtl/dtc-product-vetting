# 单位经济模型

## 为什么必须逐行列

成本表最常见的错法不是算错，是**漏行**。漏掉平台交易费 2%、漏掉组装人工、漏掉退款准备金，任何一行都能让「看起来能赚」变成「每单亏」。

另一种错法是用单一比率估算：直接按「货品成本占售价 20%」倒推。这样算出来的数看起来合理，但它不告诉你**哪一行最致命**，而敏感度分析的全部价值就在于找出那一行。

## 必含行

| 行 | 说明 | 常见取值方式 |
|---|---|---|
| 货品 | 单价 × 件数，用 R5 采信的基准值 | 区间中偏上，不用新客价 |
| 包装 | 礼盒、贺卡、防氧化袋、卡片 | 1688 同类报价区间，需正式报价替换 |
| 组装人工 | 贴标、装盒、质检 | 分钟数 × 时薪折算，**不要写 0** |
| 头程 / 直发运费 | 按重量与渠道，含跟踪号 | 市场常规区间，需货代报价替换 |
| 关税 / 税费 | 按申报价值 × 税率 | 税率未取得时用占位值，并做敏感度 |
| 支付手续费 | 通常 3.4% + $0.30 | 按通道实际费率 |
| 平台交易费 | Shopify 用第三方支付时的附加费，通常 2.0% | 按平台政策 |
| 退款 / 损耗 | 退货退款 + 破损重发 | 品类经验值，上线后替换为实测 |
| 客服 | 按单摊 | 工时 × 时薪 ÷ 单量 |

合计即变动成本。售价减变动成本 = 贡献毛利，也就是**盈亏平衡 CPA**。

## 完整实例

某饰品三件套，售价 $45：

| 成本项 | 金额 | 依据 |
|---|---|---|
| 货品 3 条 × $3.20 | $9.60 | 货源实价区间 $2.21–5.56，取中上 |
| 礼盒 + 贺卡 + 防氧化袋 | $1.40 | 同类包装报价区间 |
| 组装 / 贴标人工 | $0.50 | 3 分钟 × 时薪折算 |
| 国际小包（60–80g，带跟踪） | $5.20 | 常规区间 $4–6 |
| 关税（申报 $12 × 10% 占位） | $1.20 | 税率未取得，按 10% 占位 |
| 支付手续费 3.4% + $0.30 | $1.83 | 第三方通道常规费率 |
| 平台交易费 2.0% | $0.90 | Shopify 第三方支付附加费 |
| 退款 / 损耗 8% | $3.60 | 品类经验值 |
| 客服（按单摊） | $0.50 | — |
| **变动成本合计** | **$24.73** | — |
| **贡献毛利 / 平衡 CPA** | **$20.27（45.0%）** | $45 − $24.73 |

## 组合定价：为什么 bundle 是必需品而不是技巧

同一个穿戴甲品，三种商品结构下的平衡 CPA：

| 结构 | 售价 | 平衡 CPA | 能不能跑美国冷流量 |
|---|---|---|---|
| 单套 | $32.99 | **$12.12** | 不能。CPA 超过 12 就亏 |
| 双套 | $44.99 | $15.56 | 勉强 |
| 三套组合 | $59.99 | **$22.80** | 可以 |

三种结构的货品与物流成本差异远小于售价差异，所以**客单每提一档，平衡 CPA 涨得比成本快**。这就是为什么单件必死、组合能活。

**结论写进条件 8**：选品阶段就要判断这个品能不能做成组合。不能做组合的品，单件定价再高也过不了广告这一关。

## 敏感度：找那一行能把它做死的

固定做四档，每档给：变动成本、贡献毛利、相对基准的变化、还能不能跑广告。

| 情景 | 变动成本 | 贡献毛利 | 相对基准 | 判读 |
|---|---|---|---|---|
| 基准 $45 | $24.73 | $20.27 | — | CPA ≤ $15 仍有 $5+ 净利 |
| 降到 $39 | $23.93 | $15.07 | −$5.20 | CPA 必须 ≤ $10，勉强 |
| 提到 $49 | $25.27 | $23.73 | +$3.46 | 更好 |
| 关税 20% | $25.93 | $19.07 | −$1.20 | 可以承受 |
| 物流涨到 $8 | $27.53 | $17.47 | −$2.80 | 吃紧 |
| 退款率 15% | $27.88 | $17.12 | −$3.15 | 吃紧 |
| 货品取上界 | $31.81 | $13.19 | **−$7.08** | 危险，CPA 必须 ≤ $8 |
| 只卖单件 @ $29 | $14.69 | $14.31 | −$5.96 | 不可行，且直面零售锚 |

**读法**：看哪一行能把贡献毛利砍掉 30% 以上。砍得最狠的那一行，就是上线前必须拿到的真实数字。在这个例子里是「货品上界」和「物流」——两项都不在任何榜单里，只能问供应商和货代。

**这张表真正的作用不是预测**，是告诉你「再去查几次榜单不会让结论更确定，去要这两个报价才会」。

## 学习期算术：测试预算够不够

Meta 官方口径：广告组需在 **7 天内累积约 50 个优化事件**才能退出学习期。

反推：

```
周订单数 = 50
日订单数 = 50 ÷ 7 ≈ 7.1
所需日预算 = 7.1 × CPA
```

| CPA | 所需日预算 | 两周所需 | 四周（两个学习期） |
|---|---|---|---|
| $10 | $71 | $1,000 | $2,000 |
| $15 | $107 | $1,500 | $3,000 |
| $20 | $143 | $2,000 | $4,000 |

对照测试预算：

```
日预算 = 总预算 ÷ 天数
周订单数 = 日预算 ÷ CPA × 7
```

$1,000 / 28 天 = $35.7/天；CPA $15 时约 2.4 单/天 = **17 单/周**，只到门槛的 **1/3**。

**这条推论要说给决策人听**：$1,000 的测试预算，本身不足以让任何一个品退出学习期。它的作用不是「跑通」，而是「测出 CPA 有没有可能压到 $15 以下」。把预期写清楚，比事后解释为什么没跑起来重要。

**双品类同时上的算术**：两个品各需 50 事件/周，预算必须翻倍。预算不变时劈成两条线，两条都在学习期里，最后拿不到任何一个可信的 CPA。这是判断「能不能同站同时上两个品」的硬依据。

## 输出判据

| 平衡 CPA | 判断 |
|---|---|
| < $12 | 死。美国冷流量买不到这个价 |
| $12–18 | 只在极强素材下可行，风险高 |
| $18–25 | 可做区间，需要稳定投放能力 |
| > $25 | 好，可以承受测试成本 |
