# 六轮外部验证

按成本从低到高排序。前一轮淘汰的品不进入下一轮——这是整套流程省钱的核心。

---

## R1 · 形态与合规（零取数成本）

**目的**：在花任何时间取数之前，砍掉 60–70% 的候选。

**方法**：不需要打开任何网站。拿候选池的商品名、类目、规格，逐条对照 9 条硬筛的第 2–7 条。判定依据是品类的固有属性，不是这个品的表现。

**判据**：命中任一条即出局。遇到边界情况（如含胶水的穿戴甲），标记「待供应商确认」而不是直接放行。

**输出**：一张淘汰归因表（原因 / 数量 / 具体 ID）。这张表本身是结论——它告诉你这个市场的结构。

**典型结果**：67 → 20，淘汰 47。其中带电 18 个、大件 5 个。

**什么时候会判断错**：把「白牌」误判成「品牌自营」。判据是达人数 5000+ 且集中、同店主多品霸榜，不是「名字听起来像品牌」。

---

## R2 · 需求层（Google Trends）

**目的**：区分「平台推的」和「人主动搜的」。TikTok 上的量可能全部来自推荐流，那部分到独立站就消失了。

**路径**：`trends.google.com/trends/explore` → 地区选 United States → 时间 12 个月 → 一次输入 2–4 个词。

**方法**：必须把「目标品类词」和「一个已知有需求的对照词」放在**同一次查询**里。分开查得到的指数各自归一化，不能互相比——这是最容易犯的错。

**判据**：
- 指数 < 10 → 无自然需求，只能全额买流量
- 相对对照词 < 1/4 → 需求弱，风险高
- 词形要单独测：带连字符、带空格的变体常常差一个数量级

**输出**：四词指数对比表 + 词形结论。

**实测参考**：`press on nails` 52、`acrylic nails` 45、`fake nails` 4、`press-on nails` 1。前两个是真实需求，后两个是拼写变体陷阱。

**这一轮的价值**：它能推翻你自己排第一的品。当榜单 GMV 很高但品类词接近基线时，说明这个量是平台内循环，不是外部需求。

---

## R3 · 竞品投放（Meta 广告资料库）

**目的**：证明「有人正在为这个品类花钱」，而不是只有平台在推。

**路径**：`facebook.com/ads/library` → 国家选 US → 状态选 Active → 关键词输入品类词。

**方法**：不要数广告条数，数**独立广告主数量**；不要看素材好坏，看**每条广告的「开始投放日期」**。

**判据**：
- 首屏 10 条内 ≥5 家不同广告主 → 有真实竞争，品类被验证
- 最长连投 >30 天 → 有人靠它持续赚钱（这是最强的正面信号）
- 全部 <7 天 → 都在试，还没有人被验证

**输出**：广告主数、最长连投天数、是否有品牌级投放（同一主体投 10 条以上）。

**为什么连投时长比条数重要**：投了一周就停的是在测试；投了三个月还在投的，是已经跑通单位经济。**你看到的是别人已经付过学费的结论。**

---

## R4 · 零售锚（Walmart）

**目的**：找到美国消费者手里已有的价格参照物。这一轮通常会直接杀死「卖单件」这个选项。

**路径**：`walmart.com/search?q=<品类词>`。

**读什么**：现价、原价、评价数、配送承诺天数、是否平台自营。

**判据**：算溢价倍数 = 你的目标定价 ÷ 现货价。

| 溢价 | 判断 |
|---|---|
| < 2 倍 | 有空间，但要有明确的差异化理由 |
| 2–3 倍 | 只能靠「组合 / 定制 / 设计」撑，靠便宜和方便撑不住 |
| > 3 倍 | 死。你没有它的物流规模与议价能力 |

**输出**：价格锚表（商品 / 现价 / 原价 / 评价数 / 配送天数），以及「单件能不能卖」的明确结论。

**注意**：现价可能是促销价，必须同时记录原价，但判断按现价做——消费者此刻看到的就是这个数。

**这一轮之后常发生的事**：单件卖 $25 的路线被否，商品结构被迫改成三件套或礼盒。这不是坏事，这是提前发现了必死的路。

---

## R5 · 货源实价（AliExpress）

**目的**：把真实采购成本从「$1.09 起」里挖出来。

**路径**：`aliexpress.us` → 右上角确认 USD + 配送地址为美国 → 搜品类词。

**读什么**：不带「新购物者」标签的价格、原价（划线价）、已售件数、是否支持代发。

**判据**：
- 带新客标签的价格**一律不进成本表**（限购一件，拿不到）
- 成本取下限与上限之间：下限取与目标形态最接近的那条，上限取无促销标签的那条
- 一件代发实际拿货还要加供应商加价与汇率损耗，成本表用区间中偏上的值

**输出**：成本带（下限 / 上限 / 基准值）+ 每条价格链接。

**实测参考**：某手链采信区间 $2.20–5.60，成本表基准取 $3.20（落在区间内偏上）。

**这一轮的隐藏用途**：如果货源价极低（$1–3）而零售锚很高（$44），通常说明那个零售价只在 TikTok 站内成立，离开平台就崩。这是一条独立的否决证据。

---

## R6 · 站点结构（SimilarWeb）

**目的**：判断这个品类在独立站上「靠什么活」，从而决定你的投放策略和预期。

**路径**：`pro.similarweb.com` → Website Analysis → Traffic Overview → Traffic Sources → Channel 拆分。

**看什么**：目标品类里已跑通的站点，它的流量里 Paid Search / Paid Social / Direct / Organic Search 各占多少。

**判据**：
- 付费合计 > 40% → 这个品类高度依赖投放，你必须准备广告预算，自然流量救不了
- 自然搜索 < 20% → 没有 SEO 红利，别把时间花在内容上
- Direct 占比高 → 品牌已有认知，新站无法复制

**输出**：3–5 个同类站点的渠道结构对比表。

**实测参考**：穿戴甲赛道三个站点付费流量占比分别为 42.19%（glamnetic）、46.95%（doonails）、63.37%（curvlife）。这组数字直接否掉了「靠 TikTok 自然流量搬运」的想法——那些站的量是买来的。

**这一轮决定了什么**：它决定你的测试预算下限。付费占比 60% 的品类，没有广告预算就等于没有生意。

## 轮次间的取舍

| 情况 | 处理 |
|---|---|
| R2 需求接近基线但 R3 有人连投 90 天 | 以 R4 为准。广告主在花钱 = 有人在赚，Trends 可能低估了品类 |
| R4 溢价 >3 倍但 R5 成本极低 | 不救。低成本不构成差异化，反而说明这东西谁都能卖 |
| R6 付费占比 >60% 且你没有内容团队 | 不换品，改预期：这是纯投放生意，预算不够就别做 |
| 六轮全过但 GA 只有 $45 客单 | 仍要做。但要先算学习期需要多少钱，见 04 章 |

## 每轮的记录要求

每一轮都要留下：采集时间（精确到分钟）、数据源 URL（可点开复跑）、读到什么、判据是什么、淘汰了谁、为什么。

不留这些，报告就变成结论汇编，别人（包括三个月后的自己）无法复核。
